Mirantir

Kodi source for Mirantir, with automatic updates.

Add https://alehaaaa.github.io/mirantir/ as a Kodi file source, then choose one of these files from Install from zip file:

  • repository.mirantir-1.0.0.zip — recommended; installs the repository and enables Kodi update checks.
  • plugin.video.mirantir-1.2.0.zip — direct add-on installation.

For automatic updates, install the repository ZIP first and then install Mirantir from the Mirantir repository.
